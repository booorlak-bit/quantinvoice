# fliq.email

Менеджер инвойсов на Next.js и Supabase (Postgres) с дизайн-системой OSDS.

- `/login` — вход и регистрация по 6-значному коду из письма. Новый аккаунт сразу называет свой первый бренд (`/welcome`).
- `/dashboard` — платежи, просрочки и график оплат по месяцам.
- `/invoices`, `/clients`, `/templates`, `/payment-methods`, `/settings` — инвойсы, клиенты с проектами, шаблоны, способы оплаты, бренды и профиль.
- `/i/<slug>` — страница инвойса для клиента с кнопкой оплаты и PDF. Черновики видит только автор.

Каждый аккаунт видит только свои данные. Бренды — это проекты и сервисы, от имени которых выставляются инвойсы: у каждого свои реквизиты, логотип и нумерация. Бренд может отправлять инвойсы со своего адреса на домене `EMAIL_FROM` (например, `studio@mail.fliq.email`); адрес уникален среди всех аккаунтов, а ответы клиентов приходят на почту бренда.

## Стек

- Next.js 16 (App Router, Cache Components), React 19, Tailwind CSS 4, компоненты OSDS (Radix UI).
- Postgres в Supabase через общий пулер Supavisor под отдельной ролью `quantinvoice_app`. На всех таблицах включён RLS, а у ролей Data API (`anon`, `authenticated`) нет доступа.
- Письма (коды входа и инвойсы) отправляются через Resend; PDF собирается на сервере (`@react-pdf/renderer`, шрифт Inter).

## База данных

Миграции лежат в `supabase/migrations` и применяются по порядку. Пароль роли не хранится в репозитории:

```sql
alter role quantinvoice_app password '<пароль>';
```

## Переменные окружения

| Переменная | Зачем |
| --- | --- |
| `DATABASE_URL` | Подключение к пулеру Supabase под ролью `quantinvoice_app` |
| `SESSION_SECRET` | Случайная строка от 32 символов: подпись сессий и кодов входа |
| `RESEND_API_KEY`, `EMAIL_FROM` | Отправка кодов входа и инвойсов. Отправитель должен быть на домене, подтверждённом в Resend; с этого же домена шлют бренды со своим адресом |
| `SIGNUP_EMAILS` | Необязательно: кто может создать аккаунт (адреса или `@домены` через запятую). Без неё регистрация открыта |
| `APP_URL` | Необязательно: адрес сайта для ссылок в письмах и PDF |
| `CENTRAL_LICENSE_KEY` | Необязательно: лицензия Central Icons. С ней `npm install` ставит настоящие иконки OSDS, без неё пакет пропускается и работают заменители из `components/icons/central-fallback.tsx` |

## Локальный запуск

```bash
cp .env.example .env.local   # заполнить значения
npm install
npm run dev
```

Без Resend можно войти локально: `LOGIN_CODES_TO_CONSOLE=1` печатает коды в лог сервера.

## Деплой

Проект на Vercel подключён к этому репозиторию: каждый пуш в `main` уходит в продакшн. Переменные окружения задаются в настройках проекта на Vercel.
